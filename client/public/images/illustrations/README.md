# TaskGenie illustrations

Generated with the built-in image_gen tool for the existing TaskGenie interface. The seven transparent WebP assets share a gouache and cut-paper editorial style. Original generated PNGs are preserved in the Codex generated-images directory; the site uses compressed 768 x 512 exports with alpha retained.

Decorative usage: `ServiceIllustration` supplies empty alt text and hides scenes from assistive technology because the adjacent headings and copy explain the state. Welcome scenes load eagerly; other scenes load lazily. No external image requests or new runtime dependencies.
